# Quickstart 驗證指南：001-activity-session

用來證明 001 端對端可用，也是非實作者人工驗證（憲章原則 VI）的操作腳本。指令以 Windows PowerShell 為準。實作完成後，若實際指令與本文件不同，要在同一個 PR 更新本文件。

## 前置條件

- Python 3.11 以上（`py -3.11 --version`）。
- 一個瀏覽器，用多個分頁模擬老師與各組。
- 本子功能不使用 Google，因此不需要 `.env` 或任何憑證。

## 安裝

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

## 自動化檢查（每次提交前）

```powershell
ruff check .
ruff format --check .
mypy src
pytest                       # 單元、架構、契約、整合測試；不含 perf
pytest -m perf               # 效能測試：老師 + 6 組、每組 2 條連線（研究 R2）
```

預期結果：

- 全部通過。
- 在 PR 中記錄執行日期、指令，以及通過、失敗、略過的數字（品質關卡 4）。
- `pytest -m perf` 會輸出開輪、關輪、定案、結束各 10 次的最大延遲，每一項都必須小於 2000 ms。

## 啟動（人工驗證用）

```powershell
$env:LECTURE_QUIZ_DEV_SEED = "1"   # 002 合併前用來放入假題目；正式展示不要設定
python -m lecture_quiz              # 只監聽 127.0.0.1:8000
```

- 老師頁：`http://127.0.0.1:8000/teacher.html`。
- 學生頁：`http://127.0.0.1:8000/student.html`。
- 確認 console 只有 `INFO` 層級的 log，而且 log 中沒有任何 token 或憑證。

## 人工驗證腳本

- 23 步全部符合預期。
- 第 12、14 步的延遲都小於 2000 ms。
- 驗證紀錄寫入 PR，或 `specs/001-activity-session/verification.md`。
